# 이미지 벌크 압축기 설계

날짜: 2026-07-15 / 승인: 사용자

## 개요
macOS용 Tkinter GUI 데스크톱 앱. 이미지를 일괄 압축한다.

## 구조
- `app.py` — Tkinter GUI (드래그&드롭: tkinterdnd2, 진행률, 로그)
- `compressor.py` — Pillow 기반 처리 로직 (GUI 독립, 단독 테스트 가능)

## 기능
- 입력: JPG/PNG/WebP 파일 또는 폴더(재귀). 그 외는 건너뛰고 로그 표시
- 품질 슬라이더 1–100 (기본 80). PNG는 원본 포맷 유지 시 optimize만 적용
- 출력 포맷: 원본 유지 / WebP 변환
- 최대 가로/세로 px 지정 시 비율 유지 축소 (비우면 리사이즈 없음)
- 메타데이터(EXIF) 제거 (기본 켬)
- 출력: 각 입력 파일 위치 기준 `compressed/` 하위 폴더 (원본 무손상)
- 백그라운드 스레드 처리, 개별 실패 시 계속 진행
- 완료 후 총 절감 용량 요약 + 출력 폴더 열기

## 의존성
Pillow, tkinterdnd2
